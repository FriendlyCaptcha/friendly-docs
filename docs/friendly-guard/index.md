Friendly Guard is an upcoming product from Friendly Captcha that protects your entire site from bots and scrapers. Friendly Guard screens incoming requests to your site using the same advanced Risk Signals that power Friendly Captcha. Suspicious traffic receives a proof-of-work challenge that scales dynamically based on the risk level of the session.

Friendly Guard is built on the same core principles as Friendly Captcha: accessible, privacy-first bot protection that minimizes friction for normal traffic. Real visitors pass through unnoticed and unobstructed: no tracking, no fingerprinting, and no tedious labeling tasks.

## Integrating Friendly Guard

Friendly Guard offers multiple integration options depending on how your site is deployed.

| Self-Hosted Proxy | CDN Integrations | Direct API |
|-|-|-|
|Run the Friendly Guard proxy server in your own infrastructure.|Use a pre-built integration for the most popular CDNs.|Integrate directly in your application code using the Friendly Guard API.|

You can use the **Friendly Guard Dashboard** to configure protection rules and view detailed analytics for your site's traffic.
